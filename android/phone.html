스페이스 코드

공간을 고치고, 생활을 연결합니다. 리모델링과 IoT가 한 흐름으로 만나는 회사입니다.

Studio

우리는 리모델링을 진행하면서 동시에 IoT 기기를 설치해, 사람들에게 더 유용한 생활 편의를 제공하는 공간을 만듭니다.

Approach

공간의 형태만 바꾸지 않습니다. 사는 방식이 편해지도록 설계합니다.

벽과 동선을 다시 짜는 일, 센서와 알림·제어 장치를 심는 일을 따로 두지 않습니다. 공사 단계에서부터 기기 배치와 사용 흐름을 같이 봅니다.

Focus

우리가 붙잡는 세 가지

( 0 1 )

리모델링

( 0 2 )

IoT 설치

( 0 3 )

생활 편의

필요한 정보가 사람에게 닿게 만듭니다.

03 이어가기

생활 흐름이 끊기지 않게 확인합니다.
