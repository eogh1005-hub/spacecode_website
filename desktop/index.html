스페이스 코드

공간을 고치고, 생활을 연결합니다. 리모델링과 IoT가 한 흐름으로 만나는 회사입니다.

Studio

우리는 리모델링을 진행하면서 동시에 IoT 기기를 설치해, 사람들에게 더 유용한 생활 편의를 제공하는 공간을 만듭니다.

Approach

공간의 형태만 바꾸지 않습니다. 사는 방식이 편해지도록 설계합니다.

벽과 동선을 다시 짜는 일, 센서와 알림·제어 장치를 심는 일을 따로 두지 않습니다. 공사 단계에서부터 기기 배치와 사용 흐름을 같이 보고, 완공 뒤에도 생활이 자연스럽게 이어지게 합니다.

사람이 공간을 맞추는 것이 아니라, 공간이 사람의 일상에 맞춰 움직이는 집을 목표로 합니다.

Focus

우리가 붙잡는 세 가지

스튜디오 이야기

( 0 1 )

리모델링

낡은 구조를 정리하고, 빛·동선·쓰임을 다시 맞춥니다. 공간은 보기 좋게만이 아니라, 매일 쓰기 편해야 합니다.

( 0 2 )

IoT 설치

경보, 알림, 제어 같은 기기를 공간 계획과 함께 넣습니다. 공사 후에 덧붙이는 장치가 아니라, 처음부터 자리 잡는 인프라입니다.

( 0 3 )

생활 편의

집을 비워도, 위급 상황을 놓치지 않게. 반복되는 확인을 줄이고, 필요한 정보가 사람에게 닿게 만듭니다.

Process

공사와 기술이 같은 일정으로 움직입니다.

01 듣기

어떻게 사는지, 무엇이 불편한지부터 듣고 공간과 기기 요구를 한 장에 모읍니다.

02 맞추기

리모델링 도면과 IoT 배치를 같이 맞춥니다. 나중에 끼워 넣는 방식이 아닙니다.

03 이어가기

시공과 설치가 끝난 뒤에도 생활 흐름이 끊기지 않게 확인합니다.
